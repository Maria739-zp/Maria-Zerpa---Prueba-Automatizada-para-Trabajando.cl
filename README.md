# Maria-Zerpa---Prueba-Automatizada-para-Trabajando.cl
Este proyecto comprende la creación del flujo de inicio de sesión de un usuario registrado, así también el flujo de búsqueda básica de un puesto de trabajo para Trabajando.cl

Luego avanzamos a la creación del flujo de búsqueda avanzada aplicando los filtros necesarios. 

El objetivo es probar los componentes críticos de inicio de sesión, búsqueda de empleo y aplicación de filtros avanzados. 

# Herramientas y tecnologías

Lenguaje de Programación: Java

Entorno de Desarrollo Integrado (IDE): IntelliJ IDEA

Herramienta de Automatización Web: Selenium WebDriver.

Framework de Comportamiento (BDD): Cucumber

Gestor de Dependencias y Construcción: Maven

Gestión de pruebas: Excel

Gestion de defectos: Github issues

Navegadores Google Chrome 

Entorno: Windows 11
